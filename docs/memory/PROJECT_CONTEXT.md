# Project context

AUTO MONEY AI is a controlled autonomous-business platform for one Owner. It may conduct internal research, analysis and safe development, but it must not take outside actions or incur spend without the Owner's approval, a valid policy and a verified budget.

Current stack: FastAPI, PostgreSQL, Redis and Docker Compose. The architecture is a modular monolith. React/TypeScript and OpenAI/Codex are planned but are not active.

The monthly budget policy is USD 50, Asia/Ho_Chi_Minh, with USD 5 reserve. This remains configuration until the budget-reservation module is implemented and reconciled.
